# Corner Avenue — Calendar

The public events calendar for **Corner Avenue**, a weekly hand-curated guide to New York City's creative life — film, music, fine art, performance, makers & crafts, pottery, and gatherings.

**▶ Live calendar:** https://calendar.thecornerave.com/
**✉ Newsletter:** https://napht.substack.com

---

## What this is

A single, self-contained web page that lists creative experiences happening around the city. Readers can browse by year, month, week, or list view, filter by category, and open any event for details and a booking link. A new newsletter issue goes out weekly, and the calendar fills in as events come in.

## How it's hosted

The page is one static `index.html` file served via **GitHub Pages**. There is no backend, no database, and no tracking — everything runs in the visitor's browser.

## Updating the calendar

The calendar is maintained from a separate working copy. To publish an update, replace `index.html` in this repository with the latest version and commit — GitHub Pages redeploys automatically within about a minute.

## Suggest an event

Spotted something we missed, or run a studio with an event to share? Reply to any issue of the newsletter and we'll add it to the calendar.
